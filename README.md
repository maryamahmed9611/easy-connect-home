# Easy Connect Home

Create a simple, accessible home screen for an elderly care app called "Smart Elderly Care." Design specifically for elderly users who are not comfortable with technology.

Requirements:

- One home screen with exactly 3 large square buttons, stacked vertically, each taking up most of the screen width

- Button 1: "Medical Support" with a red cross or heartbeat icon

- Button 2: "Daily Needs" with a grocery basket or shopping icon

- Button 3: "Talk to Family" with a phone or family icon

- Use very large text (at least 24px) and large tap targets (buttons at least 100px tall)

- Use high contrast colors: dark text on light background, or the reverse, avoid low-contrast pastel colors

- Add a small microphone icon in the top corner that represents a voice assistant feature

- Keep the design extremely simple, minimal, and uncluttered, no unnecessary elements or menus

- When each button is tapped, navigate to a new screen that shows: a large text area displaying "Listening..." with a pulsing microphone icon, followed by an empty text box where spoken text will later appear

- After the "Listening" screen, show a third screen type: a "Confirmation" screen with a checkmark icon, large text saying "Request confirmed" and a "Done" button that returns to the home screen

Use a calm, warm color palette (soft blues, greens, or warm neutrals) appropriate for an elderly-focused wellness app. Make sure everything is centered and readable without scrolling on a phone screen.
